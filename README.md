# 记账

手机上的多人记账本（默认两个人，可自己增减，最多 8 个）。纯前端，无需安装、无需注册、不联网，数据只存在你自己的手机里。

---

## 怎么在手机上用

### 方式一：放到 GitHub Pages（推荐，能加到主屏幕当 App 用）

本地仓库已经初始化并提交好了，只差建远程仓库和推送。

1. 在 GitHub 上新建一个仓库，名字 `money-book`，选 **Public**
   - **不要**勾选 "Add a README file"、"Add .gitignore"、"Choose a license"，
     否则远程会有本地没有的提交，第一次推送会被拒绝
2. 推上去（远程 `origin` 已经配好了，只剩推送）：
   ```bash
   cd D:\ai\money-book
   git push -u origin main
   ```
   第一次推送会弹出登录窗口，用浏览器授权一次即可。
3. 仓库页面 → **Settings → Pages** → Source 选 `Deploy from a branch`，Branch 选 `main` / `root` → Save
4. 等 1 分钟，访问 `https://Sisyphus13579.github.io/money-book/`
5. **手机上打开这个网址** → 浏览器菜单 → 「添加到主屏幕」

之后桌面上就会出现一个叫「记账」的图标，点开是全屏的，和 App 一样。

> Android 用 Chrome、iPhone 用 Safari 添加效果最好（Safari 添加后是全屏 + 无地址栏）。
>
> **这一步只需要成功打开一次。** 打开后所有文件会被存进手机，之后断网、飞行模式都能正常用。

### 方式二：电脑开个小服务器，手机连同一个 WiFi 访问

```bash
cd D:\ai\money-book
npx serve -l 8080        # 或者 python -m http.server 8080
```
然后手机浏览器访问 `http://<电脑的局域网IP>:8080`。

缺点有两个：电脑不开就用不了；而且这是 `http://`，浏览器认为不安全，**不允许注册
service worker**，所以没有离线能力，也加不到主屏幕当 App，只能当书签用。

### 方式三：直接把文件夹拷到手机

能打开，但 Chrome 对 `file://` 下的本地存储限制较多，且同样加不到主屏幕。**建议用方式一。**

## 没有网络能用吗

**能。第一次打开之后，就再也不需要网络了。**

页面文件（HTML / CSS / JS / 图标）由 `sw.js` 这个 service worker 在首次打开时整个存进手机，
之后断网、飞行模式、地铁里没信号，照样正常打开和记账。数据本来就只在手机本地，从不上传。

细则：

- **第一次打开必须联网**（从网址加载一次即可），之后就永久离线可用
- 断网时改动代码不会生效，恢复网络后自动拉取新版，**不需要清缓存**
- 这个能力只在 `http://` / `https://` 下生效。直接双击 `index.html`（`file://`）时浏览器不允许注册 service worker，但那样本来也不依赖网络
- 如果哪天想彻底重置，在浏览器设置里清除该网站的缓存数据即可

## 多人怎么用

这个手机上的账本是「多个人共用一个账本」的模式，默认两个人，自己可以增减：

- **顶栏左上角** 是当前使用者头像，点它可以切换「现在是谁在记账」
- 新记的每一笔，默认算在当前使用者头上；记账时也能临时改（记账面板右下角的那个人名按钮）
- **明细页顶部** 可以按 `全部 / 我 / TA / …` 筛选，看各自花了多少
- **图表页** 有「谁花得多」卡片，列出每个人这个月的支出对比
- **「我的」页** 可以添加 / 删除使用者，也能改名字、换头像、换颜色

### 添加和删除使用者

「我的 → 使用者 → 添加使用者」，填个名字、挑个头像和颜色就行。**最多 8 个** ——
色板只有 8 个经过色盲校验、互不相撞的槽位，再加就会出现两个人同色。新增时会自动
挑一个还空着的颜色，删掉一个再加回来也会回收那个空槽。

删除在「我的 → 使用者 → 点那一行的 ✎ → 删除」。有两条保护：

- **名下有记录时会先问你怎么处理** —— 可以「转给某个使用者」，也可以「连同 N 笔一起删」。
  不会出现把人删了、他的账变成没人认领的孤儿数据的情况（那样筛选和统计都会漏账）
- **最后一个人删不掉** —— 账本总得有个归属

删掉的如果正好是当前使用者，会自动切到剩下的第一个人；如果正好在按他筛选，会自动切回「全部」。

> 想两台手机各记各的？用「我的 → 导出备份 / 导入备份」手动合并（会覆盖，不能自动合并）。

## 功能

| 页面 | 能做什么 |
|---|---|
| **明细** | 本月支出/收入/结余、较上月涨跌、按天分组的流水；点任意一笔可看详情、编辑、删除 |
| **图表** | 近 6/12 月收支柱状图（点柱子出提示）、分类占比环形图（点分类高亮）、「谁花得多」多人对比 |
| **日历** | 月历视图，每天的支出多少用蓝色深浅表示，点某天看当天流水 |
| **预算** | 月度总预算 + 分类预算，进度条 + 剩余 + 日均可用，超支标红提醒；预算会自动沿用到之后的月份 |
| **我的** | 使用者增删改（最多 8 个）、分类管理、账户管理、主题（跟随系统/浅色/深色）、导出/导入/清空 |

记账面板是**全屏自定义数字键盘**，不用弹系统键盘，单手也能快速记一笔。

## 数据安全

- 数据存在浏览器的 `localStorage`（键名 `moneybook_v1`），**不会上传到任何服务器**
- 整个应用没有任何外部请求（无 CDN、无字体、无统计、无接口），只有页面自身的 9 个文件
- 清除浏览器数据会一起清掉，所以**建议偶尔去「我的 → 导出备份」存一份 JSON**
- 换手机：旧手机导出 → 新手机导入
- 深色模式下夜间记账不刺眼


无框架、无构建工具、无依赖，改完直接刷新页面就生效。

## 技术说明

**图表配色经过校验，不是凭感觉挑的。** 8 个分类色相通过了两项检查：

- **色盲可辨度**：相邻色对最差 ΔE 9.1（浅色）/ 8.4（深色），高于 8 的门槛，红绿色盲也能区分
- **对比度**：深色模式下 8 个颜色对背景都 ≥ 3:1

配套规则：

- 默认分类正好占满 8 个色槽，**保证环形图里不会出现两个同色扇区**；用户自己加的分类会复用色槽，此时靠图例里的「图标 + 名称 + 金额」区分 —— 颜色从不单独承载信息
- 「其他」是聚合桶，固定用中性灰，不占用任何色相
- 支出 = 蓝、收入 = 红（中式记账习惯：进账为红），两者 ΔE 21.6，绝不会看混
- 日历热力图是单一蓝色由浅到深（浅 = 花得少），格子里同时印了金额，不靠颜色猜数
- 预算进度条的轨道色是填充色的同色系浅一档，空/满在同一色系里读
- 所有超支状态都带「⚠ 超支」图标和文字，不只靠红色

**关于修改分类数量**：色板只有 8 个经过色盲校验的色相，所以默认支出分类是 8 个 + 「其他」。
如果你新增到第 9 个以上，会出现两个分类共用一个颜色 —— 这在小尺寸图表里是难免的，
图例里的图标和名称仍然能区分。想要更多分类又不想撞色，可以考虑拆成两个账本或合并低频分类。
